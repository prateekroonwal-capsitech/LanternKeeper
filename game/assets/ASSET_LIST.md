# Lantern Keeper — Asset List

All asset placeholders are generated by scripts in `tools/`:
- `tools/generate_player.py`: player animation strips, the lantern arm, and `player_frames.tres`
- `tools/generate_enemy_art.py`: enemy silhouette art (SVG sources → PNG frames), SpriteFrames, eye tracks, contact sheet
- `tools/generate_enemies.py`: enemy eyes, lairs, and thread
- `tools/generate_placeholders.py`: environmental props, backgrounds and UI controls
- `tools/generate_audio.py`: synthesized placeholder music loops and SFX `.ogg` files

To swap in final art, overwrite the file **with the same name and pixel size**
(Godot re-imports it automatically). Sprites are drawn on `Sprite3D` nodes, so
world size = pixel size × the node's `pixel_size`.

## Player (the boy) — animation strips

Located in `game/assets/sprites/player/`, generated by `tools/generate_player.py`.
Each strip is a horizontal row of **192 × 192** frames. Feet sit 4 px above the frame
bottom, centred horizontally (pivot = bottom-centre, via Body offset `(0, 96)`; `pixel_size` 0.009
→ the boy is ≈ 1.5 m tall). The boy faces **right**; the game flips him for left.
`Body.modulate` is HDR (1.8) so the white eyes glow.
Frames are wired in `player_frames.tres` (SpriteFrames) — replace a strip with the same
size and frame count and nothing else changes.

`_carry` strips draw the **near arm holding the lantern** into the body silhouette: short,
bent, the hand at hip height — always at the same pixel, **(15, 66) px from the frame's
bottom-centre** (= `Player.hand_carry_point` 0.135, 0.594 m). `raise_*_carry` frames hold it
overhead at **(16, 128) px** (= `hand_raise_point`). Final art must keep the hand on those
pixels — `Player/HandMarker` sits there and the lantern's handle hangs from it.
Rotated and stretched in-game to reach the lantern handle.

## Enemies

Original silhouette designs, generated by `tools/generate_enemy_art.py` (needs `pip install resvg_py pillow`).
Each frame is an SVG source in `game/assets/source/enemies/<enemy>/` (Godot ignores that folder) rendered
at 2× size to a transparent PNG in `game/assets/sprites/enemies/<enemy>/<anim>_<nn>.png`. Alpha is the
silhouette; the red channel holds faint inner detail lines that `enemy_silhouette.gdshader` tints toward
the rim colour. Every frame of every enemy is on `game/assets/source/enemies/contact_sheet.png`.

Each folder also holds `<enemy>_frames.tres` (SpriteFrames, 10–12 fps) and `eyes.json` (eye position per
frame, copied into the scene's `EnemyVisual.eye_track`). The PNGs are imported VRAM-compressed with mipmaps
and an import **size limit** (the art is drawn at 2×), so the Body's `pixel_size` = art metres-per-pixel ×
(art size / limit). To replace a frame, overwrite the PNG with the same size and keep the creature's
origin pixel; re-run the generator to rebuild everything.

## Text

All UI text is translation keys in `localization/strings.csv` (column `en`). Add a language
by adding a column (e.g. `fr`) and adding its `.translation` file to Project Settings →
Localization; it then appears in Settings → Language automatically.
