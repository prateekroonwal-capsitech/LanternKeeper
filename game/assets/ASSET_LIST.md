# Lantern Keeper — Asset List

Every asset is a placeholder generated by `tools/generate_placeholders.py`.
To swap in final art, overwrite the file **with the same name and pixel size**
(Godot re-imports it automatically). Sprites are drawn on `Sprite3D` nodes, so
world size = pixel size × the node's `pixel_size`.

## Player (the boy) — animation strips

Generated by `tools/generate_player.py` into `sprites/atlases/animations/player/`.
Each strip is a horizontal row of **192 × 192** frames. Feet sit 4 px above the frame
bottom, centred horizontally (pivot = bottom-centre, via Body offset (0, 96); pixel_size 0.009
→ the boy is ≈ 1.5 m tall). The boy faces **right**; the game flips him for left.
Frames are wired in `player_frames.tres` (SpriteFrames) — replace a strip with the same
size and frame count and nothing else changes. To change frame counts or fps, edit the
SpriteFrames in the editor (Player.tscn → Body).

| File | Frames | Size (px) | FPS / loop | Notes |
|---|---|---|---|---|
| `player_idle.png` / `player_idle_carry.png` | 6 | 1152 × 192 | 6, loop | Breathing; frame 5 blinks. |
| `player_walk.png` / `player_walk_carry.png` | 8 | 1536 × 192 | 10, loop | Played when speed < 4 m/s (joystick half-tilt). Speed-scaled. |
| `player_run.png` / `player_run_carry.png` | 8 | 1536 × 192 | 14, loop | Speed-scaled. |
| `player_jump.png` / `player_jump_carry.png` | 3 | 576 × 192 | 10, once | Take-off → rise → apex. |
| `player_fall.png` / `player_fall_carry.png` | 2 | 384 × 192 | 6, loop | Arms up. Also used when a fall kills. |
| `player_land.png` / `player_land_carry.png` | 3 | 576 × 192 | 14, once | Only after falls faster than 6 m/s. |
| `player_place.png` | 4 | 768 × 192 | 14, once | Crouch to set the lantern down. |
| `player_death.png` | 6 | 1152 × 192 | 10, once | Collapse when caught by a shadow. |
| `player_arm.png` | 1 | 64 × 20 | — | The lantern arm. **Shoulder at x = 5, vertically centred**, hand at the right end. Rotated + stretched in-game to reach the lantern handle. |

`_carry` strips are the same poses **without the near arm** — while carrying, the game
draws `player_arm.png` instead and aims it at the lantern. If your final art adds a
different arm length or shoulder position, set `Player → Lantern arm → shoulder_offset /
arm_length` in the Inspector.

## Audio

All synthesized placeholders from `tools/generate_audio.py`. Replace with any `.ogg` of the
same name (any length). Assignments live in `game/resources/audio_library.tres` (Inspector).
Music and the heartbeat are looped in code, so no import setting is needed.

| File | Length | Plays when |
|---|---|---|
| `audio/music/menu.ogg` | 32 s loop | Main menu / level select |
| `audio/music/world_1_light.ogg` | 32 s loop | World 1 levels (crossfades between worlds) |
| `audio/music/world_2_oil.ogg` | 32 s loop | World 2 |
| `audio/music/world_3_shadows.ogg` | 32 s loop | World 3 |
| `audio/music/world_4_mirrors.ogg` | 32 s loop | World 4 |
| `audio/sfx/jump.ogg` | 0.2 s | Jump (slight random pitch) |
| `audio/sfx/land.ogg` | 0.25 s | Landing from a real fall |
| `audio/sfx/lantern_place.ogg` | 0.5 s | Lantern set down |
| `audio/sfx/lantern_pickup.ogg` | 0.45 s | Lantern picked up |
| `audio/sfx/oil_pickup.ogg` | 0.5 s | Oil flask |
| `audio/sfx/shrine.ogg` | 2 s | New checkpoint lit |
| `audio/sfx/death.ogg` | 1.1 s | Any death |
| `audio/sfx/heartbeat.ogg` | 1 s loop | Dark meter below 45 % — louder and faster as it empties |
| `audio/sfx/ui_button.ogg` | 0.07 s | Every UI button |
| `audio/sfx/level_complete.ogg` | 1.8 s | Reaching the exit |

Buses (`default_bus_layout.tres`): **Master** ← Music, SFX. The settings sliders drive these.

## Text

All UI text is translation keys in `localization/strings.csv` (column `en`). Add a language
by adding a column (e.g. `fr`) and adding its `.translation` file to Project Settings →
Localization; it then appears in Settings → Language automatically.
